# Examples

Sample files for Demo Co., a fictional software company. They're generated by
`scripts/make_demo_data.py` from the same drivers as the built-in demo, so importing them gives
the same numbers.

| File | What it shows |
|---|---|
| `demo_pl_quickbooks_2026.csv` | Actual P&L, January to September 2026, laid out like a QuickBooks Online export: title rows, sections, nested payroll section, totals, a total column and a footer |
| `demo_budget_2026.xlsx` | FY2026 budget as an analyst would build it: one row per account, months across, with a few accounts that need confirmation when mapping |

Try:

```bash
openvariance inspect demo_pl_quickbooks_2026.csv
openvariance variance --actual demo_pl_quickbooks_2026.csv --budget demo_budget_2026.xlsx \
  --accept medium --period 2026-09 --dashboard september.html --open
```
